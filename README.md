# Microsoft Cognitive Services — exemplo

> Aplicativo de demonstração para serviços cognitivos da Microsoft, desenvolvido em Xamarin.Forms.

## Organização

- `Droid/` — projeto da plataforma Android.
- `Poc.Luis.Xamarin/` — projeto ou módulo `Poc.Luis.Xamarin`.
- `iOS/` — projeto da plataforma iOS.

Solução: [`Poc.Luis.Xamarin.sln`](Poc.Luis.Xamarin.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`Poc.Luis.Xamarin.sln`](Poc.Luis.Xamarin.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
